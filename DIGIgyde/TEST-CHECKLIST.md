# DIGIgyde Frontend Demo Test Checklist

- [ ] Open `index.html` with Live Server.
- [ ] Sign in as resident using the demo credentials.
- [ ] Confirm dashboard, service cards, and seeded requests appear.
- [ ] Submit a new service request.
- [ ] Open My Requests and view request details.
- [ ] Sign out and sign in as administrator.
- [ ] Open Service Requests and view the new request.
- [ ] Change its status and add an admin note.
- [ ] Sign out and return to the resident account in the same browser.
- [ ] Confirm the updated status is visible.
- [ ] Publish an announcement as admin.
- [ ] Register a new resident account and confirm it opens the resident dashboard.
- [ ] Check profile editing and digital ID display.
- [ ] Refresh the browser and confirm local data persists.

Note: this checks only local browser behavior. It does not verify secure authentication or cross-device synchronization.
